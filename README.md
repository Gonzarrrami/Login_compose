# Login_compose

App Android de dos pantallas hecha 100 % con Jetpack Compose: un Login con validación y una pantalla de Bienvenida con fuegos artificiales dibujados en Canvas. No usa layouts XML, librerías de navegación ni ViewModel.

## Datos de prueba

| Campo | Valor |
| --- | --- |
| Correo | `sulbaranjc@gmail.com` |
| Contraseña | `1234` |
| Nombre mostrado | Juan Carlos |

Son datos de ejemplo del tutorial, escritos a propósito en el código.

## Mejoras opcionales incluidas

- Modo oscuro con `darkColorScheme` en la Bienvenida. El Login es siempre oscuro, como su diseño original.
- El botón **Iniciar sesión** se desactiva si algún campo está vacío.

## Créditos

- Basado en el tutorial [Login_compose](https://github.com/sulbaranjc/Login_compose) de Juan Carlos Sulbaran Gonzalez.
- El diseño del Login es una adaptación de [Login Page](https://www.figma.com/community/file/1244126388179404671/login-page), de Adarsh, publicado en la comunidad de Figma con licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Cambios: textos traducidos al español, logo añadido, campos de correo y contraseña con mostrar/ocultar, y mensaje de error.
